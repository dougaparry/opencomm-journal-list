# #opencomm Journal List

**Website: https://dougaparry.github.io/opencomm-journal-list/**

A website for the **Open Media and Communication Research (#opencomm) Journal List**: peer-reviewed journals in media and communication research that support open science, such as full open access, no article processing charges, registered reports, open peer review and open data.

The list is created and maintained by Moritz Büchi, Michael Reiss, and Tobias Dienlin in a [Google Sheet](https://docs.google.com/spreadsheets/d/1WDTBIop2Eg9CKsvQ1BUgMXJdmrh1TAreyS02SiWEJDY/edit?gid=0). The website pulls its data directly from that sheet and updates automatically.

To suggest a journal or report outdated information, comment on the sheet or request edit access there.

The website is built by [Douglas Parry](https://dougaparry.com/) as an independent project and is not directly affiliated with the list’s authors.
