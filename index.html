Open Media and Communication Research #opencomm – Journal List

A curated list of peer-reviewed journals in media and communication research that support open science. Compare full open access, article processing charges (APC), registered reports, open peer review, open data, open science badges, openness to replications, and indexing in DOAJ, Web of Science and Scopus.

About this list

Created by Moritz Büchi, Michael Reiss, and Tobias Dienlin.

Last update 04/2026, inclusion of journals "Platforms & Society", "Contratexto", "Creator and Influencer Studies", "Palabra Clave", "JMIR Infodemiology", and "Journal of Medical Internet Research".

About this website

This website was built by Douglas Parry. It pulls its data directly from the #opencomm Google Sheet, which is created and maintained by the list’s authors. The website is an independent project and is not directly affiliated with them.

Inclusion criteria

Open science features (hybrid open access alone does not qualify), peer-reviewed, publishes English language articles, focused on Media and Communication generally, on subdisciplines (e.g., science communication, media psychology, etc.), or generalist / other disciplinary journals open to Media and Communication (e.g., PLOS ONE)

Suggest a journal or report an error

Please comment or request edit access if you see outdated/false info or would like to add a journal.
